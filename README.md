# Statistics Homeworks

A small static website for university statistics assignments, built using HTML, CSS, and JavaScript.

## Pages
- `index.html` — homepage
- `homework-1.html` — interactive educational ECC toy-curve experiment and statistical discussion
- `homework-2.html` — placeholder for the Ethereum wallet homework

## Preview
Open `index.html` in a browser, or use Live Server in VS Code. No build process or dependencies are required.

## Publish
Push the contents of this folder (not the enclosing folder) to the root of a GitHub repository. In **Settings → Pages**, deploy from the `main` branch and `/ (root)`.

**Security:** This is educational demo code, not a production cryptographic implementation. Never use real wallet secrets.
