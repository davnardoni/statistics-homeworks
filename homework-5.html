Homework 5 — Numerical Integration and Normal CDF

Comparing Riemann and Lebesgue integration through numerical experiments, and investigating efficient methods for computing the standard normal CDF.

Exercise 1 — Riemann and Lebesgue Integration

1. Introduction

Riemann and Lebesgue integration are two mathematical approaches to computing integrals. Although they produce the same result for Riemann-integrable functions, they differ in how they partition the problem.

Riemann integration partitions the domain of a function, while Lebesgue integration considers the sets of points associated with different function values. We implement numerical approximations inspired by both definitions and compare their convergence and efficiency.

2. Riemann integration

The Riemann integral approximates the area under a curve by dividing the domain into subintervals. Each subinterval contributes the area of a rectangle.

We use the midpoint rule, evaluating the function at the center of each subinterval:

\[ R_n = \sum_{i=0}^{n-1} f\left(a+\left(i+\frac12\right)\Delta x\right) \Delta x, \qquad \Delta x=\frac{b-a}{n} \]

As the number of subintervals increases, the approximation generally becomes more accurate for Riemann-integrable functions.

3. Lebesgue integration

Lebesgue integration follows a different perspective. Instead of dividing the horizontal axis, we consider different levels of function values and measure the domain points that reach each level.

For a bounded nonnegative measurable function, the layer-cake representation gives:

\[ \int_a^b f(x)\,dx = \int_0^M \mu\left( \{x\in[a,b]:f(x)\geq t\} \right)\,dt \]

Here, \(M\) is an upper bound for the function, and \(\mu\) denotes Lebesgue measure. We divide the range into \(n\) levels and apply a midpoint approximation:

\[ L_n = \Delta y \sum_{j=0}^{n-1} \mu\left( \left\{ x\in[a,b]: f(x)\geq \left(j+\frac12\right)\Delta y \right\} \right) \] \[ \Delta y=\frac{M}{n} \]

In our implementation, the measures of these sets are determined analytically for each function. This allows us to compare domain and range partitions without introducing an additional sampling error in the Lebesgue method.

5. Discussion of the results

For the continuous and piecewise constant functions, both methods converge to the same exact integral. Their numerical errors may differ because the methods partition different axes.

The pathological examples reveal a more important distinction. The Dirichlet function equals 1 at rational points and 0 at irrational points. It is not Riemann-integrable because every interval contains both rational and irrational numbers. However, its Lebesgue integral is 0 because the rational numbers have measure zero.

The Thomae function assigns \(1/q\) to a rational number \(p/q\) in lowest terms and 0 to irrational numbers. Unlike Dirichlet's function, it is Riemann-integrable, and both integrals equal 0.

Conclusion

The experiments confirm that Riemann and Lebesgue integration agree whenever the function is Riemann-integrable. Lebesgue integration also handles functions such as Dirichlet's, for which the Riemann integral does not exist.

Both implemented algorithms require O(n) operations when the preimage measures are available analytically. For general functions, computing these measures may be more expensive, so the measured runtimes are specific to our implementation.

Exercise 2 — Numerical Computation of the Normal CDF

1. Introduction

The cumulative distribution function (CDF) of the standard normal distribution gives the probability that a random variable \(Z\sim N(0,1)\) takes a value less than or equal to \(z\).

\[ \Phi(z)=P(Z\leq z) =\frac{1}{\sqrt{2\pi}} \int_{-\infty}^{z} e^{-t^2/2}\,dt \]

Unlike many common probability distributions, the normal CDF cannot be expressed using only elementary functions. This makes its numerical computation an important practical problem.

2. Liouville's theorem and the error function

The difficulty comes from the fact that the function \(e^{-t^2}\) has no elementary antiderivative.

Liouville's theorem on elementary antiderivatives provides a mathematical explanation. In this case, an elementary antiderivative would require a rational function \(R(t)\) satisfying \(R'(t)-2tR(t)=1\), but no such rational function exists.

To represent this integral exactly, we introduce the error function:

\[ \operatorname{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2}\,dt \]

Through a change of variables, the normal CDF can be written exactly in terms of this special function:

\[ \boxed{ \Phi(z)=\frac12 \left[ 1+\operatorname{erf} \left(\frac{z}{\sqrt2}\right) \right] } \]

This gives an exact analytical representation, but the error function itself still needs to be evaluated numerically in practical applications.

3. Numerical methods

We implement three approaches and compare them in terms of accuracy and computational cost.

Method 1 — Composite Simpson's rule

Simpson's rule approximates the integral by fitting quadratic polynomials over pairs of subintervals. Using the symmetry of the normal distribution, we can avoid integrating from negative infinity:

\[ \Phi(z)=\frac12+ \frac{1}{\sqrt{2\pi}} \int_0^z e^{-t^2/2}\,dt \]

The integral is then evaluated over a finite interval. Simpson's rule has fourth-order convergence for sufficiently smooth functions.

Method 2 — Power series expansion

Another approach is to expand the exponential function into its Taylor series and integrate term by term. This gives:

\[ \Phi(z)=\frac12+ \frac{1}{\sqrt{2\pi}} \sum_{k=0}^{\infty} \frac{(-1)^k z^{2k+1}} {2^k k!(2k+1)} \]

In practice, we truncate the series once the terms become sufficiently small. The method works well near the origin, but cancellation can reduce its numerical reliability for large values of \(|z|\).

Method 3 — Error function approximation

The third approach uses the approximation of the error function given by Abramowitz and Stegun (formula 7.1.26). It replaces direct integration with a short polynomial computation.

The approximation has an absolute error below \(1.5\times10^{-7}\) for the error function, making it a fast method for evaluating the CDF.

5. Discussion of the results

The results show that all three methods provide accurate CDF estimates for the selected values. Simpson's rule improves as the number of subintervals increases, while the power series is especially effective near the origin.

The error function approximation has a small, fixed approximation error and requires only a few arithmetic operations. It is therefore particularly attractive when many CDF evaluations are needed.

Conclusion

Although the normal CDF has no elementary closed-form expression, the error function provides an exact mathematical representation. Numerical integration, series expansions, and special-function approximations make its practical computation possible.

Simpson's rule offers controllable accuracy, the power series is effective near zero, and the erf approximation provides an efficient solution with a known error bound.
